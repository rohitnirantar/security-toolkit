## Approach

1. **Learn**: read the standard or technique from the source.
2. **Write it down in your own words**: if you cannot explain it simply, you have not learned it.
3. **Apply it**: turn it into a template, checklist, query or rule.
4. **Review**: revisit notes monthly; fix errors and date what you change.

## Good primary sources

- NIST: [CSF 2.0](https://www.nist.gov/cyberframework), [SP 800-61 (incident handling)](https://csrc.nist.gov/pubs/sp/800/61/r3/final), SP 800-63B (digital identity)
- [MITRE ATT&CK](https://attack.mitre.org/) and [D3FEND](https://d3fend.mitre.org/)
- [CISA Known Exploited Vulnerabilities catalog](https://www.cisa.gov/known-exploited-vulnerabilities-catalog)
- [CIS Controls and Benchmarks](https://www.cisecurity.org/controls)
- [OWASP](https://owasp.org/) (Top 10, ASVS, Cheat Sheet Series)
- [SigmaHQ rules](https://github.com/SigmaHQ/sigma)
- [LOLBAS](https://lolbas-project.github.io/) and [GTFOBins](https://gtfobins.github.io/)

Link to sources rather than copying documents into this repo; many are copyrighted or change over time.
